Privacy policy: Personal Comms Warehouse

Last updated November 11, 2026

Personal Comms Warehouse is a personal tool used by one person, its owner, on their own Gmail account. It is not available to the public.

What it accesses

With the owner's consent, it uses the read-only Gmail scope (gmail.readonly) to read the owner's own messages. It cannot send, modify or delete mail.

How data is used and stored

  • Messages are copied into a private database on a server the owner controls, so the owner can search their own mail.
  • Data is not sold, shared, or transferred to third parties, and is not used for advertising.
  • Google user data is not used to train generalized AI or machine-learning models.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removal

The owner can revoke access at any time at myaccount.google.com/permissions and delete the stored archive from their server.
